# Portfolio — Acil Kadri

Portfolio professionnel de développeur Front-End, réalisé dans le cadre de ma formation OpenClassrooms.

## Stack technique

- React + Vite
- Tailwind CSS v4
- React Router
- Iconify (icônes)

## Fonctionnalités

- Pages projet dédiées avec navigation
- Dark mode avec persistance localStorage
- Responsive mobile/desktop
- Lazy loading des pages
- Optimisation SEO et accessibilité

## Installation
```bash
npm install
npm run dev
```

## Déploiement

Déployé sur Vercel : https://portfolio2026-mu-sandy.vercel.app/
